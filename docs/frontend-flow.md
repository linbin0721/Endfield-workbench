# 前端流程

本文描述当前三个工具页的交互流程与状态规则；视觉、组件和样式约定见 `ui-design.md`，语言见 `i18n-design.md`，325 数据与计算见 `calculator-design.md`。首版原型的流程与 T03 验收记录保留在 `tasks.md` 与 `TASK.md` 的历史中。

## 站点结构

- 路由为 `/:locale/` 首页及 `balloon`、`circuit`、`325` 三个工具页；无语言前缀的旧地址按浏览器语言重定向。导航、首页入口和路由都来自 `web/src/tools/registry.ts` 一处清单。
- 工具页代码按需加载；代码分块与语言资源并行获取。代码加载失败时显示“页面加载失败”，重试会重新载入页面（浏览器会缓存失败的动态导入）。
- 切换语言或主题不重挂载工具、不重新提交任务，已选图片、题面和答案都保留。

## 解谜工作台（浮空回收、源石电路）

两种解谜共用 `features/workbench/` 的导入、进度、帮助和任务部件，题面、编辑与答案绘制各自实现。

### 三步与状态

页面顶部的进度条依次为“导入 → 题面 → 答案”。页面根元素的 `data-flow` 给出当前状态：`import`、`recognizing`（上传/识别或题号查询中）、`puzzle`（题面待确认或待补全）、`solving`、`answer`、`failed`。

### 导入

- 不再有“截图识别 / 按题号查询”的入口切换：图片投放区与题号输入并排（窄屏上下排列），用户直接选一种开始。
- 图片可选择文件、拖放、在页面中粘贴，电脑另可截取游戏窗口（见下节）。选中后显示整图；切到“手动裁剪”可在图上拖动裁剪框或拖角缩放，方向键微调、Shift 加大步长。框停稳后在浏览器内生成 PNG，非整图范围才上传裁剪图。
- 只有点击“识别并求解”才上传当前选定范围。更换或清除图片会取消进行中的任务并清掉题面和答案。
- 帮助面板（右侧抽屉）放截图范围示意、题号位置和注意事项，不占用主流程。

### 识别后的题面

- 识别出完整题面时自动提交求解。
- 识别出的题面缺数字或数据不一致时停在题面步，缺失项标红并列出待补项，不自动求解。
  - 浮空回收：可改格子（可放置/禁用）和库存升力、数量；截图上方的目标总升力只用于核对库存，可改正或清空，不提交求解器。
  - 源石电路：只有后端返回可编辑草稿时才停在题面（契约见 `circuit-recognition-draft.md`）；可改各颜色的行列目标数字、障碍和固定格，先选颜色再改；拼块按截图识别，不可编辑。无草稿时仍提示换图。
- 截图识别出的题面都可以“修改题面”后重新求解。修改后，原答案标为过期并变暗，直到重新求解；“恢复识别结果”回到识别原值。
- 提交给求解接口的始终是完整校验过的普通题面，不包含草稿、缺失原因或显示色板。

### 题号与目录候选

- 题号查询得到的题面只读。只有一个题面时直接求解；有多个时以“题面 A / B”卡片并排展示棋盘、库存与观察次数，选中后求解。
- 截图识别带有目录候选时（存在争议、题面不完整、或截图题面不可用但目录唯一可靠），候选卡片与识别出的题面一起列出；与本次截图一致的候选会标出并默认选中。冲突的记录从不合并。

### 答案

- 答案画在重绘的棋盘上，不叠加到截图原图上（叠加以后单独成批，需要后端返回格子坐标）。
- 浮空回收显示每格气球的升力、平衡轴与行列力矩；源石电路先用 `deriveCircuitAnswer` 独立重建并校验全部摆放，通过后才绘制，校验失败时显示错误而不画答案。
- 无解与达到计算上限分开说明；限时未穷尽时不声称无解。

### 任务

- 同一页面同一时刻只有一个服务端任务（`useTaskRunner`）：提交、每 700ms 轮询到终态。新任务、取消、更换图片或离开页面都会作废旧任务并请求服务端取消；作废后的迟到响应不再更新页面。
- 取消识别会清空本次结果；取消求解保留题面，可以直接再次求解。

## 图片导入与截图入口（EW-016）

- 设备模式只由 UA、平台和触控能力判断：Windows、macOS、Linux 默认电脑；Android、iPhone、iPad 默认移动，包含以桌面 UA 上报的触控 iPad；窗口宽度和单独触控信号不改变模式，触屏 Windows 仍是电脑。
- 电脑在选图旁显示“截取游戏窗口”，窗口缩小不隐藏；手机和平板不渲染该按钮，主按钮使用相册文案。常用操作在移动端保持至少 44px 触控区域并允许换行，长文件名不溢出。
- 截屏在点击事件内直接调用 `getDisplayMedia`（`audio:false`，`displaySurface:"window"` 只是首选提示），由用户自行选择游戏窗口；不做自动框选、桌面助手或自动上传。首个可绘制视频帧转成 PNG 后立即停止所有 track，并沿用选图流程做本地预览；仍需点击“识别并求解”才上传。
- 不支持 `getDisplayMedia` 或非安全上下文的电脑显示禁用按钮，并提示改用选图、拖放或粘贴。
- 无帧、来源结束、拒绝授权、清除、更换图片、路由卸载和新的截屏尝试都会使旧尝试失效并释放资源；截屏等待可取消，取消或失败不会替换当前预览。保持 12 MiB / 2000 万像素限制。

## 服务连接（EW-020）

- 能力查询有 10 秒总上限，包含等待响应和读取 JSON；超时或返回无法使用的能力列表时，页头的服务状态显示错误并提供“重试连接”。
- 服务未就绪时识别与查询按钮保持禁用；重试保留已选截图，不自动上传或重复创建任务。路由卸载取消查询，迟到响应不覆盖新页面。
- 该上限只用于能力查询；上传、求解与任务轮询保持各自行为，不自动重试。

## 325 配装台

- 左侧为条件：干员（头像网格加搜索）、等级（滑块、±1 和数字框）、潜能、必须同时达到 325 的属性和高级上限。计算在浏览器 Worker 中完成，不上传。
- 右侧在搜索前显示所选干员和空装备槽；搜索后先给出方案对比表（四项面板值、达标数、武器），点选一行即在配装台显示该方案的干员、武器与基质、四个装备槽及锤炼、激活套装和复制按钮。
- 面板属性以到 325 的进度条显示，并按干员、武器、装备、套装拆分来源，写出“固定值 × (1 + 百分比) = 原始值 → 面板值”。拆分用计算器导出的函数按 `evaluateBuild` 的顺序重放，只有与 `raw` 逐位相等的属性才显示拆分，否则只画总值。
- 修改任何条件都会作废当前结果；搜索中可取消，切换语言不重启搜索。

## 移动端与可访问性

- 从 320px 宽起可用，页面不出现横向滚动；宽屏把题面与答案并排，窄屏按导入、题面、答案纵向排列，结果首次出现在视口下方时自动滚入视野（减少动效时不平滑滚动）。
- 常用操作有文字标签和至少 44px 的触控区域；棋盘格在编辑时是按钮，带行列位置和状态的可访问名称。禁用格、未识别格、气球、障碍和固定格同时用图案或文字区分，不只依靠颜色。
- 任务状态、错误和待补项通过 `role="status"` / `role="alert"` 或 `aria-live` 读出；焦点使用统一的焦点环。

## 测试钩子

脚本依赖的稳定属性：`data-flow`、`data-service`、`data-task-status`、`data-puzzle-panel`（编辑中另有 `data-editing`）、`data-answer-panel` 与 `data-answer-source`（`screenshot` / `edited` / `code` / `candidate`）、`data-solution`、`data-answer-board`、`data-cell`、`data-circuit-placement`、电路棋盘的 `data-mode`；325 的 `data-calc`、`[data-bench]`、`tbody tr[data-selected]`、`data-breakdown`。输入框 `#image-file`、`#question-code`、`#circuit-question-code`。改动这些属性时同步告知集成方。
