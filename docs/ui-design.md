# 界面设计

本文记录 EW-026～033 前端重做后的界面约定：风格、设计令牌、主题、布局与组件、各工具的棋盘绘制、动效、响应式、可访问性和体积预算。交互流程见 `frontend-flow.md`。

## 风格

- 方向是“终末地游戏风”：深色与浅色两种底面，单一高亮色为游戏界面的亮黄 `#fff200`；细线分隔、条码与刻度装饰、面板角标、网格底纹、斜切角。用户允许在统一风格下设计得更“炫”，不必照搬游戏界面。
- 工具页的视觉重点是题面与答案：答案用重绘的棋盘表达（气球的发光球体、电路的整块渐变拼块、325 的分段属性条），装饰不能遮挡或改变业务信息。
- 截图原图、API 返回的电路色板和题面数据不重新着色；只有显示层可以为主题调整明暗（见下文“电路配色”）。

## 设计令牌与层序

- `web/src/ui/styles/tokens.css` 定义原始值：黄色高亮、`ink` 灰阶、状态色、稀有度色、字号（`--fs-xs`～`--fs-display`）、间距（4px 基数的 `--space-*`）、圆角、控件高度和动效时长。组件不直接用原始值。
- `surfaces.css` 按 `data-surface="dark" | "light"` 给出语义变量：页面、面板、卡片和行的底色，文字三级，边框，控件，强调色及其文字色，焦点环，状态色等。新样式只使用这些语义变量。
- 层序为 `@layer base, components, overrides;`：基础重置在 `base`，组件和页面 CSS Modules 在 `components`，后层总是胜过前层，与选择器权重无关。不再新增全局样式；旧的全局 `styles.css` 和 `legacy` 层已在 EW-033 删除。
- 字体：界面文字用系统字体并按语言回退到对应的中日韩字体；数字、编号和英文标题用自托管的 Barlow（latin 500/700）。

## 主题

- 默认浅色。用户选择保存在 `localStorage` 的 `ew-theme`；`index.html` 中的内联脚本在首次绘制前设置 `<html data-surface>`，避免闪烁。读写存储失败时按默认值处理。
- 切换主题时，支持的浏览器以 View Transition 做斜向擦除过渡；减少动效时立即切换。弹层（对话框、抽屉、下拉）通过同一个 surface 上下文取得主题。

## 布局与通用组件

- 站点框架（`web/src/shell/`）：顶栏导航（带滑动指示条）、手机抽屉菜单、语言选择、主题切换、品牌标志、页脚、加载态与 404。
- 通用组件（`web/src/ui/`）：`Button`（primary / accent / secondary / ghost）、`IconButton`、`SegmentedControl`、`Select`、`Dialog`、`Drawer`（左侧菜单，右侧加宽用于帮助）、`Panel`（可带角标）、`PageHeader`（条码眉题）、`SectionTitle`（色条标题与刻度线）、`Notice`（info / success / warning / danger）、`SuccessReveal` 与 `SuccessGlow`、`ThemeToggle`、图标集，以及 `useChangeCount`（结果变化时重放成功动画，语言切换不重放）。
- 解谜工作台（`features/workbench/`）：页头（标题、服务状态、帮助按钮）、三步进度条、导入面板（投放区带扫描框角标，选图后显示带棋盘格底的预览框与裁剪框）、题面与答案两栏、等待态（网格底纹，忙碌时有扫描光带）。
- 页面结构统一为“页头 → 主要面板 → 结果”；面板之间用 `--space-5` 间距，面板内容用 `--space-4`～`--space-6`。

## 棋盘与结果绘制

- 浮空回收：格子保持游戏的宽高比；禁用格为斜纹，未识别格为红色虚线加问号；答案中的气球是带高光的青绿色球体并显示升力，依次弹出，棋盘中心画出横竖平衡轴。
- 源石电路：棋盘上方是列目标、左侧是行目标，每个颜色一组色块数字；编辑时只显示当前颜色的目标输入。障碍为斜纹加叉，固定格为通道色块加菱形；答案为 SVG，每个拼块一个整体渐变和外轮廓，按顺序放入。
- 电路配色：色板来自 API 的色相；暗色主题原样使用，浅色主题只在显示层提高拼块深色端和轮廓的亮度（`features/circuit/circuitTheme.ts`），色相、通道和颜色名不变。色板无效时整体改用固定的高对比示意色并注明。
- 325 配装台：装备槽用斜切角卡片，武器槽顶边为武器色、装备槽为装备色；锤炼与基质等级用斜刻度点表示；属性条按来源分色（干员蓝、武器黄、装备青绿、套装紫），竖线标出 325。

## 动效

- 时长用 `--dur-*` 令牌；成功横幅、气球弹出、电路拼块放入、属性条增长都只在新结果出现时播放，语言切换不重放。
- `prefers-reduced-motion: reduce` 时所有动画和过渡缩短到近乎为零，滚动不平滑。

## 响应式

- 从 320px 起可用，侧边距 16px，不出现页面横向滚动。宽屏两栏（题面/答案、325 条件/结果），窄屏单栏。
- 长文本允许换行（`overflow-wrap: anywhere`）；表格等宽内容在自身容器内处理，例如 325 对比表在窄屏改用属性简称并隐藏武器列。
- 解谜结果首次出现在视口下方时自动滚入视野。

## 可访问性

- 焦点统一使用 `--focus-ring`（按底面区分颜色）；所有交互元素可键盘操作，裁剪框与拖角支持方向键。
- 编辑中的棋盘格是按钮，可访问名称包含行列（从 1 开始）、状态和操作提示；状态信息用 `role="status"`，错误用 `role="alert"`。
- 信息不只靠颜色：禁用、障碍、固定格、未识别、达标都有图案、文字或形状区分。

## 预算与验证

- 首页冷加载 JS+CSS gzip 不超过 `7e40b51` 基线 +30 KB（EW-033 时约 +19 KB）；woff2 字体合计不超过 60 KB（约 44.8 KB）。工具页按需加载，不计入首页。
- 前端改动至少运行类型生成、生产构建、`test:i18n`，涉及 325 时运行 `test:calculator`；用浏览器在深浅两种主题、四种语言和 320 / 390 / 1024 / 1366 宽度下检查无溢出、无报错。
- 风格样张（EW-026 的 `/design-preview/`）已在 EW-033 删除，后续设计改动直接在正式页面上验证。
