# 终末地解谜助手 · MVP PRD

版本：0.4｜日期：2026-09-18

## 目标与用户

为《明日方舟：终末地》玩家提供网页解谜工具。MVP 仅实现浮空回收（气球）：用户导入完整清晰的游戏画面，一次点击识别并求解，获取可照着操作的答案。源石电路（拼块）留好扩展接口，完整功能后置。

电脑用户可上传或粘贴截图，手机用户从相册选图；PS 用户可用手机拍摄屏幕后导入。

## MVP 范围（用户已确认）

- 气球谜题具备真实的图片识别与自动求解能力。
- 源石电路仅预留模块注册及识别、求解接口约定，不实现识别、编辑器或求解功能；未实现接口明确返回未支持状态。
- 后端无法确定的地块仍返回未知，前端求解时默认视作禁用；不编造库存数字。页面不显示识别草稿和手动编辑器。
- 库存缺数、题面无效或识别失败时提示用户换一张包含完整棋盘和右侧所有气球库存的清晰截图。
- 求解后显示可与游戏题面对照的摆放方案。
- 前端先保证功能可用、操作清楚、兼容电脑和手机。终末地风格的视觉重做属于后续工作，不计入首版验收。

## 使用流程

进入气球解谜 → 导入图片 → 点击“识别并求解” → 库存完整且题面有效时直接查看答案。若库存缺数或题面无效，换一张清晰完整的截图重试。答案棋盘仅在放置气球的格内显示升力数字。

识别失败时允许换图重试。等待过程显示识别和求解阶段；输入冲突、无解、服务不可用和计算超时须分别说明，超时不能报告为无解。选图和本地预览不会自动上传，点击“识别并求解”后才上传。默认上传完整原图；手动裁剪为可选操作，页面仅展示一张实际将上传的图片预览与像素尺寸。

## 首版工作假设

以下用于控制开发范围，尚未获得逐项确认，可后续调整：

- 优先支持清晰、完整、重置后的游戏截图；拍照图片允许导入，暂不承诺与截图相同的识别效果。
- 返回一种可行解，以完整摆放图配合气球升力数值展示。
- 保留玩家已摆放部分、最少移动优化、全部解枚举和逐步动画不纳入首版。
- 首版不提供账号、云端历史记录或题库，不替用户操作游戏。

## 验收标准

1. 气球谜题使用真实题目样本完成“导图—识别并自动求解—核对答案”的完整流程，并记录样本与结果。不能以演示数据或占位接口代替完成。
2. 识别缺失关键字段时不提交求解，并提示用户换一张完整清晰的截图；更换图片或裁剪范围不会让旧任务覆盖新结果。
3. 正常结果满足已核实的玩法规则；失败与超时有明确提示。
4. 电脑和手机浏览器均能完成核心流程，无阻碍操作的布局问题。
5. 图片直传自有服务器，不通过 Vercel 中转；待处理任务与同时计算数量有上限。
6. 源石电路保留独立模块接入位置和能力声明；其识别与求解接口不可误报为可用，完整功能不计入 MVP 验收。

识别准确率、支持的具体规则变体和高并发响应时间，需通过样本与实测明确，不预先承诺未验证的数值。

## 实施边界

Vercel 托管 TypeScript 前端；自有服务器运行 Python 后端，首版统一承担识别与求解。图片临时处理，不默认永久保存。架构详见 `architecture.md`，分阶段交付详见 `tasks.md`；基础骨架完成不代表 MVP 已完成。
