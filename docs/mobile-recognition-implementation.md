## 定位实验与决定

旧定位器以灰度阈值 130 提取明亮外框，再寻找同排至少三个连续框和至少两排的规则排列。旧图有 16 个白框，能得到 5×5；图 1 和图 3 各只有 5 个白框，前者分散，后者只占中间一排，因此均返回 `no_board`。

对调参图的灰色地块轮廓试了阈值 30、35、40、45、50、55、60、65、70。45 附近可取得包括灰格的完整或近完整规则排列：旧图、图 1 均检出 25 个对齐格，图 3 检出 22 个；排列聚类仍得出完整 5×5 尺寸和位置。30–35 有较多灰格漏检，55 以上有明显的内轮廓重复，65–70 漏掉暗格。因此固定使用阈值 45 只定位棋盘几何，再以原阈值 130 的白框与网格坐标匹配，标记 `usable`。其他格保持未知；灰格轮廓用于推断完整网格，并未仅凭白框缺席自动标记 `blocked`。这是一组有限截图的参数选择，不代表一般屏摄或其他界面亮度的最优值。

进度 OCR 使用棋盘上方中间分区；库存 OCR 使用棋盘右侧分区，范围按检测出的棋盘宽高计算，沿用原有 `(right+0.30×宽, top-0.06×高)` 至 `(right+1.55×宽, bottom+0.18×高)`。没有从原图固定像素位置裁切，也没有预填题号或题目答案。目标总升力用于显示与核对，也用于在唯一性与容量约束全部满足时严格推导单个缺失项（见“严格推导”一节）；没有其他补值来源。

调参图上的库存圆圈数字 1 常被 OCR 读成 `V`。只在库存行的文字 OCR 明确含“升力”和数字时，才从该行文字框右端附近截取数字小分区（横向相对框右端约 `-0.515×格宽` 至 `-0.223×格宽`，纵向中心 `±0.24×格宽`）。当原圆圈裁剪未可靠读出数字时，另取圆圈中心偏左的紧裁剪；两个小分区都以至少 0.85/0.8 置信度读出同一数字才补入草稿。原圆圈与文字数字都可靠却冲突时留空并提示核对。库存标签“几级回收气球”不当作升力，因为旧图 4 级的升力为 6。该文字本身以 ≥0.8 置信度读出单个数字时也作为独立证据补充缺失升力（多位数字视为箭头歧义，不采用），规则见下节。旧图最下行当时因缺少可靠一致证据而留空；其库存为 6×3 / 3×3 / 2×3、目标 36，如果目标 OCR 置信度达到下述门槛，严格推导会把它补为 1×3。

## 严格推导（2026-09-27）

新增 `api/app/puzzles/balloon/derive.py`，全部是不读取图像的纯函数。库存草稿只在以下条件全部成立时补一个缺失项，否则保持空值：

- 目标总升力 OCR 置信度 ≥0.85，且本轮没有发生库存总升力冲突。冲突中留空的 count 不再由同一个目标回填。
- 形态一：所有 lift 已识别且唯一，恰好一个 count 缺失，按 `(目标 − 已知加权和) / lift` 恢复。
- 形态二：恰好一行 lift 与 count 都缺失、其余行完整；枚举 lift 1..100 与 count 1..剩余容量，排除已有 lift，只有唯一因子对时恢复。
- 两种形态都要求残差 >0、正整数、单项与总 count ≤18、总 count ≤已识别 usable 格数，并复核最终加权总升力等于目标。0 解或多解保持空值。
- 推导成功时 issues 写明第几行和推导出的值，例如“第 4 行库存的升力和数量均缺失：已按目标总升力 18 唯一推导为升力 1 × 3 个，请核对。”只有仍有缺失字段时才追加通用提示。

库存 OCR 文本本身以 ≥0.8 置信度读出“升力”和数字时，该数字作为独立证据：与圆圈或文字裁剪证据一致时补入缺失升力，冲突则留空；“N级回收气球”的 N 不参与。文字把“1”和箭头读成“11”一类多位数字时按歧义处理，不采用，避免把已识别的升力改成错误值。

## 规则纵轴子序列（2026-09-27）

旧定位器把与候选列对齐的同尺寸轮廓全部当作行，再要求每一段行距都等于列距。191530 的页面底部叠加层在第一列横坐标附近产生了一个同尺寸远端轮廓，候选因此被当成不规则的第六行而整体丢弃，识别落到右侧四列；191752 没有该轮廓，所以同一题面得到 5×5。现在按列距（±15%）把纵坐标切成极大连续区段，只把间距与列距一致的连续区段当作行候选，再按候选实际对齐的格子数评分。远端同尺寸轮廓自成一个区段，不再扩展或否决完整网格；`usable` 仍只由明亮外框决定，暗格轮廓只用于确定几何，评分与未知格语义不变，也没有文件名或固定像素坐标特例。

新增公共回归测试 `test_regular_rows_ignore_distant_same_size_outliers`：合成 5×5 深色格网，并在棋盘下方或上方加入同尺寸远端轮廓，断言始终得到 5×5、可放格只来自明亮外框且棋盘范围不含离群轮廓，不依赖任何私有截图。
