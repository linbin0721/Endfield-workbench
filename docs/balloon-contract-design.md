# T02 气球求解的设计边界

本文件是实现约束；实际字段以实现后的 OpenAPI 为准，不表示功能已经完成。

## 规则范围

初始规则版本仅表示矩形棋盘以几何中心为支点、各气球升力按行列距离产生力矩。每格最多一个气球，禁用格不能放置，库存必须全部使用，允许可放置格留空。两个方向的总力矩均为零才是合法解。

用两倍整数坐标表示距离：列坐标为 `2 * column - (columns - 1)`，行坐标同理。这样奇偶尺寸都不需要浮点容差。此规则与现有样本一致，且于2026-09-17获得用户明确确认；接口和界面说明使用中心行列距离计算平衡。

## 输入与输出

- 输入包含规则版本、棋盘尺寸、可放置格、按升力归并的库存。坐标从零开始；拒绝重复坐标、越界、非法数量、未知字段和不支持的规则版本。
- 题目数据只包含求解所需信息，不携带图片。识别草稿可以缺字段，求解输入必须完整且通过校验。
- 输出区分找到解、已证明无解、达到计算限制。只有穷尽搜索或数学上排除所有可能时才可报告无解。
- 成功结果给出每个气球的行、列和升力，附上使用数量、总升力和两个方向的力矩供核对。
- 返回前由独立校验函数重新检查地块、唯一性、库存和力矩；校验失败属于内部错误，不将不合法布局展示给用户。

## 计算边界

首版只返回一个解。限定尺寸、库存规模、搜索时间和搜索工作量；请求不能自行调大服务端上限。计算在现有工作进程内进行，定期检查截止时间。超时必须结束实际搜索并释放槽位，不能只修改任务状态。

求解器使用自己实现的数学约束，不复制许可不明确的参考仓库。用用户样本验证解，再用小规模独立穷举交叉验证可解和无解情况。已有工作进程队列、取消与过期语义保持一致。

## 接入顺序

先完成输入模型、独立答案校验、求解和 API，再生成前端类型。源石电路仍保持不可用。图片识别仍保持不可用，直至后续任务以真实图像通过验收。
