# 分阶段任务与验收

产品范围以 `prd.md` 为准。MVP 当前实现气球图片识别与自动求解；用户于 T08 要求移除手动校正界面。源石电路仅预留接口与模块位置。前端首版以可用和手机适配为验收要求，视觉风格重做后置。以下已验收任务保留当时的范围与记录。

由主代理负责架构、任务边界和独立验收；同一个 gpt-5.6-sol / high 子代理负责编码。上一任务通过后才下发下一任务。不派发整站一次性实现任务，也不按单文件拆分。

2026-09-16 主代理独立运行 `pytest -q -p no:cacheprovider`：9 passed in 12.74s，正常退出。已覆盖队列容量、真实 spawn 子进程、取消、失败释放容量、结果保留、闲置 TTL 清理、完成参数释放、CORS 和错误响应。当前环境默认 pytest 缓存插件在退出写缓存时卡住，测试命令关闭该插件。强制终止仍未实现，后续真实计算必须另有执行时间边界。

验收：配置与接口类型正确；队列容量限制有效；执行不阻塞 API；失败能回收容量；排队取消有效；运行中取消语义诚实；TTL 与任务数有界；Windows 进程启动与关闭无残留。

## T07 一次点击识别与求解（已验收）

2026-09-18 按用户最新要求，前端将识别草稿中的未知格默认设为禁用，库存完整时自动提交求解；后端仍保留未知识别数据，库存缺失不猜测。此交互覆盖 T05a 的逐格确认要求。答案棋盘移除可见坐标与空格文字，仅在摆放气球处显示升力，保留无障碍位置说明和手动校正入口。

主代理独立生产构建通过；375 像素真实浏览器验证手机图1与图3，一次点击分别产生一次识别 POST 和一次求解 POST，未知格归零，答案无可见坐标，页面无横向溢出。旧截图缺少末行库存时仅识别并提示补齐；补齐后只提交求解，不重复上传，返回12个气球、总升力36、两轴力矩0。

通过浏览器拦截并延后真实响应检查竞态：识别成功响应尚未送达时取消，不触发求解；识别创建响应延迟时更换图片，旧结果不覆盖新图、不触发旧题求解，新图仍可一次点击得到答案。此验收针对本地流程，不等于公网部署或任意照片识别率保证。
