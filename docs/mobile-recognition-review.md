# 手机截图识别修复与验收

2026-09-18。三张新增原图均为2844×1280，存放在被忽略的 `samples/private/balloon-mobile-{1,2,3}.jpg`，不进入前端资源或发布包。

## 已复现的问题

主代理调用真实识别入口，三张原图均返回 `no_board`。旧定位器只使用明亮白框定位可放格，要求横向连续格、多排和至少六个对齐轮廓，无法据稀疏可放格还原完整棋盘。图片3只有中间一排白框；图片1只有五个可放格。单纯裁剪不能补上缺失的定位依据。

主代理另对调参图1和3比较三个归一化棋盘裁剪框 `(left,top,right,bottom)`：`(.38,.21,.62,.72)`、`(.39,.23,.61,.70)`、`(.35,.18,.65,.76)`。旧定位器在这六个组合上均未定位出棋盘，支持先修正几何定位依据的选择。

## 修复边界

- 棋盘定位利用包括灰色地块在内的完整网格证据，不能把可放置区域的外接矩形当作完整棋盘。
- 定位后分别裁出棋盘、库存、进度总升力；自动裁剪在后端完成，保留原图供定位与人工校正。
- 参数按棋盘尺寸与位置归一化，记录实际对比结果；没有足够样本时不声称找到适用于所有设备的最优值。
- 明确灰格的视觉证据才可标记禁用；不确定仍保留未知。库存不能从总升力反推后当作识别值。
- 旧图、新图、缩放、黑边和只含棋盘的图均需核对尺寸与逐格坐标；已摆放图和无棋盘图仍须拒绝或给出明确提示。
