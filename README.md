# 终末地解谜助手

网页工具，首版目标为气球谜题的图片识别、手动校正与求解。前端部署到 Vercel，浏览器直接访问自有服务器上的 Python API。源石电路仅预留扩展位置。

## 当前进度

- 气球MVP的本地流程已通过验收：真实截图识别、手动校正、求解和答案校验；手机与桌面布局已检查。
- 识别不清的信息保留未知。当前样本有限，尚未验证任意拍屏图片的识别效果。

## 已支持的求解规则

当前支持明确标识为 `center-torque-v1` 的规则：以矩形棋盘几何中心为支点，气球升力按距中心的行、列距离分别加权，左右与上下各自平衡。5×5 棋盘中，中心距离为 0，相邻格为 1，外圈为 2。每格最多一个气球，并使用全部库存。支持 2–6 行、2–6 列，最多 18 个气球。

提供题面后返回一组经过独立校验的可行解，或者明确的无解、计算限额结果。计算限额不表示无解。单次任务耗时和服务器承载量需要在实际部署环境中测量。

## 样本

用户提供的原始截图只保存在被忽略的 `samples/private/` 中，不进入网页静态资源或公开仓库。图片识别回归测试在原图存在时运行，并在测试过程中生成缩放图和棋盘裁剪图；缺少私有截图时相应测试明确跳过。坏图、上传限制和超时测试不依赖私有截图。求解测试代码中的棋盘和库存为人工整理的数值样本，不是图片识别结果。
