# 网页本地运行

需要 Node.js 20.19+。先在 `api/` 启动单进程 API，再从 `web/` 运行：

```powershell
npm ci
Copy-Item .env.example .env.local
npm run generate:api
npm run dev
```

打开 `http://localhost:5173`。如 API 不在本机，请将 `.env.local` 中的 `VITE_API_BASE_URL` 改为自有 API 的公开 HTTPS 地址；它是浏览器直接访问的地址，不能填密钥。后端 `CORS_ORIGINS` 必须包含网页实际域名。Vercel 项目根目录设为 `web`，配置同一个公开环境变量即可。静态托管不代理 API 请求。

验证生产包：

```powershell
npm run generate:api
npm run build
```

气球图片识别和求解已接入真实 API。选择图片和预览都在浏览器内进行；点击“识别并求解”才会直传自有 API。默认上传完整原文件，服务尝试自动定位棋盘及库存，不在浏览器生成整图 PNG。需要时可开启手动裁剪：仅开启后显示百分比控件和裁剪输出预览，非完整范围转为 PNG，裁剪输出须不超过 12 MB；100% 范围仍上传原文件。页面显示实际上传的像素尺寸。截图应包含完整棋盘和右侧所有气球库存。

识别出的未知格在求解时视为禁用；后端原始草稿仍保留未知。库存数字完整且题面有效时自动求解，结果棋盘仅在摆放气球的格内显示升力数字。库存缺数、题面无效或识别失败时明确提示换一张完整清晰的截图，不猜测数字；页面不提供手动编辑与单独求解入口。更换图片、调整裁剪或取消会使旧任务结果失效。源石电路留作后续支持。
